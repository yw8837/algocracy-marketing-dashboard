# 화면·기능 검수 기록

**검수일:** 2026-09-15

## 데스크톱

1440×1000 전체 화면에서 사이드바, 히어로, KPI, 제작 파이프라인, 5일 캘린더, 선택 콘텐츠 상세, 분석·솔루션 표, 자동화 지도가 순서대로 표시된다. 아이보리·포레스트 그린·코랄·노랑의 편집실형 디자인이 일관되고, 숫자가 없는 KPI는 `—`와 `수집 전`으로 표시된다. 캘린더 첫 항목이 기본 선택되며 Instagram 구성과 Threads 원고가 같은 화면에 노출된다. 텍스트 잘림이나 가로 오버플로는 관찰되지 않았다.

## 모바일

390×844 전체 화면에서 단일 열로 전환되며 히어로, 주간 브리프, KPI, 캘린더 목록, 선택 콘텐츠 상세, 인사이트, 자동화 카드가 자연스럽게 이어진다. 데스크톱 사이드바는 숨겨지고 상단 메뉴 버튼으로 대체된다. 카드와 표는 모바일에서 세로 구조로 변환되어 가로 스크롤 없이 읽을 수 있다. CTA와 상태 라벨의 대비도 유지된다.

## 빌드

`node scripts/build-insights.mjs`, `pnpm check`, `GITHUB_PAGES=true pnpm build`가 통과했다. 성과 CSV에 행이 없기 때문에 집계 스크립트는 숫자를 만들지 않고 빈 상태를 유지했다. production build는 성공했으며 큰 JS 청크에 대한 성능 경고만 있다. 이는 기능 오류가 아니며 이후 라우트 분리 시 최적화할 수 있다.

## GitHub 연결

기존 GitHub 커넥터 토큰은 만료돼 CLI 인증이 실패했지만, 사용자가 브라우저에서 다시 로그인했다. GitHub의 새 저장소 생성 화면에서 소유자 `yw8837`이 확인됐으며 `algocracy-marketing-dashboard` 저장소 생성과 최종 소스 push를 진행할 수 있는 상태다.

## 2026-09-15 실사용 화면 전면 재검수

참조 디자인 가이드에 따라 긴 소개형 스크롤 페이지를 탭 기반 운영 앱으로 재구성했다. 데스크톱 1440×1000에서 오늘의 운영 화면은 경고, KPI, 5일 제작 현황, 다음 콘텐츠와 채널 역할 순으로 한 화면에 배치된다. 카드 반경과 그림자를 줄이고 선과 표면 차이로 정보 위계를 만들었다. 고정 사이드바는 전체 페이지 캡처 정책상 스크린샷에서 숨겨졌으나 실제 미리보기에서는 정상 표시된다.

모바일 390×844에서는 메뉴 버튼, 화면 제목, 성과 입력 버튼이 상단에 유지된다. KPI와 사이드 패널은 단일 열로 전환되고, 콘텐츠 진행 현황은 가로 스크롤 없이 표시된다. 제목·상태·CTA의 잘림이나 겹침은 관찰되지 않았다. 성과 입력은 하단 시트 형태로 열리며 Escape와 배경 클릭으로 닫힌다.

`pnpm check`와 production build가 통과했다. 현재 SEO·트래픽·GEO 수치는 데이터 소스가 연결되지 않아 의도적으로 표시하지 않으며, 검색 화면에 `연결 필요` 상태와 필요한 소스를 명시한다.

## 탭·검색 화면 동작 검수

실제 미리보기에서 사이드바의 `검색 인사이트`를 클릭해 화면 전환을 확인했다. 별도 페이지 새로고침 없이 SEO·AEO·GEO 준비도, 5일 키워드 구조와 발행 전 체크리스트가 표시된다. 검색량·순위 데이터가 없는 상태를 `연결 필요`와 `검색량 미수집`으로 명확히 표시하며 임의 수치는 없다. 공식 Instagram·Threads 링크와 저장소 링크도 상단·사이드바에서 외부 링크로 구분된다.

## 성과 입력 동작 검수

실제 미리보기에서 상단 `성과 입력` 버튼을 눌러 모달이 열리는 것을 확인했다. Instagram 조회수 필드에 숫자를 입력할 수 있으며 입력 제약은 0 이상의 숫자다. 테스트 값은 저장 버튼을 누르지 않아 로컬 데이터에 반영되지 않았다. 모달에는 CSV 내보내기, 저장, 닫기와 미수집 값을 빈칸으로 두라는 안내가 함께 표시된다.

## 입력 취소·콘솔 검수

숫자 입력 테스트 후 저장하지 않고 닫아 초기 `수집 전` 상태가 유지되는 것을 확인했다. 브라우저 콘솔에는 오류나 경고 출력이 없었다.
