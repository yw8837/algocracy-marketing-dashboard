# 브랜드 자산 사양

## 확인한 공식 자산

| 브랜드 | 파일 | 출처 | 사용 |
|---|---|---|---|
| 알고크라시 | `client/public/brand/algocracy.png` | `https://algocracy.ai/assets/apple-icon-180x180.png` | 앱 아이콘·브랜드 식별 |
| 슈퍼패스 | `client/public/brand/superpass.png` | `https://www.superpass.io/logos/apple-touch-icon-180.png` | 제품 식별 |
| 알고크라시 OG | `client/public/brand/algocracy-og.png` | `https://algocracy.ai/assets/og.png` | 외부 공유·브랜드 참고 |
| 슈퍼패스 OG | `client/public/brand/superpass-og.jpg` | `https://www.superpass.io/logos/superpass-og.jpg` | 외부 공유·브랜드 참고 |

알고크라시 아이콘은 검은 단색 심볼이며 투명 배경이다. 슈퍼패스 아이콘은 밝은 배경 위 검은 `SPPS` 워드마크다. 화면에서는 임의의 로고를 그리지 않고 이 자산을 사용한다. 다만 대시보드의 시각적 주도권은 콘텐츠와 상태 정보에 두며, 로고는 내비게이션 상단에서만 제한적으로 노출한다.

## 공식 문구 기준

알고크라시는 기술로 더 나은 결정을 돕는 회사라는 설명을 사용한다. 슈퍼패스는 실제 경험과 지원 직무의 맥락을 바탕으로 자소서 구조를 설계한다는 표현을 우선한다. 합격 보장, 확인되지 않은 성과와 임의의 수치는 사용하지 않는다.
