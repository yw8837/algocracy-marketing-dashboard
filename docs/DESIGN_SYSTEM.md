# 디자인 시스템

## Design Read

이 대시보드는 `@world.needs.u`를 운영하는 마케터가 매일 여는 업무 도구다. 첫 화면의 역할은 소개가 아니라 **오늘 발행할 콘텐츠, 확인하지 않은 성과, 가장 먼저 고칠 문제**를 빠르게 보여주는 것이다. 시각 언어는 참고 작업의 실무형 B2B 운영 화면을 기반으로 하되 알고크라시의 포레스트 그린과 따뜻한 아이보리를 유지한다.

| 항목 | 결정 |
|---|---|
| 모드 | 기존 대시보드의 구조를 유지하되 실사용 중심으로 재설계 |
| 시각 변동성 | 4/10 — 개성은 컬러보다 정보 순서와 문장 톤에서 확보 |
| 모션 강도 | 2/10 — 상태 변경과 모달 전환에만 사용 |
| 정보 밀도 | 8/10 — 한 화면에서 오늘 할 일과 지표를 확인 |
| 자산 의존도 | 5/10 — 공식 로고와 실제 계정·사이트 링크 사용 |
| 브랜드 충실도 | 8/10 — 알고크라시·슈퍼패스의 실제 문구와 색을 우선 |

## 화면 역할

데스크톱은 1m 거리의 업무 화면, 모바일은 10cm 거리의 승인·기록 도구로 본다. 첫 화면은 `오늘의 운영`, 캘린더는 `제작 현황`, 분석은 `증거 → 진단 → 조치`, 검색 섹션은 `SEO/AEO/GEO 준비 상태`, 자동화는 `연결 상태와 수집 신뢰도`를 담당한다.

## 시각 규칙

배경은 차가운 회색이 아닌 따뜻한 중립색을 사용하고, 주요 표면은 흰색에 가까운 아이보리로 둔다. 모서리는 6–10px, 그림자는 모달과 드로어에만 쓴다. 상태는 색과 문구를 함께 표시한다. 제목은 Pretendard 중심으로 바꾸고, 숫자나 강조 문장에만 세리프를 제한적으로 쓴다. 영어 라벨은 짧은 기능 분류에만 사용한다.

## 실사용 원칙

작동하지 않는 버튼은 두지 않는다. 미수집 수치는 대시로 표시하고 `수집 전`을 붙인다. 성과 입력은 로컬 저장 후 CSV로 내보낼 수 있다. 콘텐츠 상태는 화면에서 바꾸고, 다음 작업이 무엇인지 명확히 보이게 한다. SEO·트래픽 데이터는 데이터 소스가 연결되기 전에는 숫자를 만들지 않고 `연결 필요`로 표시한다.
