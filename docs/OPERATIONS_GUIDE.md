# 마케팅 대시보드 운영 가이드

## 매일 사용하는 순서

오전에는 캘린더에서 오늘 콘텐츠의 첫 문장, Instagram 구성, Threads 원고와 CTA를 확인한다. 문구와 링크 검수가 끝나면 상태를 `검수 대기`로 바꾸고, 최종 승인 뒤 게시한다. 게시가 끝나면 상태를 `발행 완료`로 변경한다.

게시 후 24시간, 72시간, 7일에 플랫폼 인사이트를 확인한다. 상단의 `성과 입력`을 눌러 조회수, 저장, 문의처럼 실제로 확인한 값만 기록한다. 수집하지 못한 값은 빈칸으로 둔다. 필요한 경우 `CSV 내보내기`로 기록을 보관한다.

## 금요일 회고

조회가 낮으면 훅과 대상 표현을 먼저 본다. 조회는 있으나 저장이 낮으면 체크리스트나 판단 기준처럼 다시 꺼내 쓸 요소가 부족한지 확인한다. 저장은 높지만 링크 클릭이 낮으면 마지막 CTA와 프로필 링크의 문구가 같은지 확인한다. Threads에서 조회는 있으나 답글이 없다면 질문을 선택형 또는 한 줄 경험형으로 줄인다.

## 게시 금지 조건

확인하지 않은 합격 사례와 성과 수치는 사용하지 않는다. 무료진단의 실제 경로, 개인정보 안내와 운영 여부를 확인하지 않은 상태에서 신청을 유도하지 않는다. 댓글 자동 DM이 실제 계정에서 연결·테스트되기 전에는 댓글을 남기면 링크를 보내준다는 문구를 사용하지 않는다.

## 데이터 관리

화면에서 입력한 값은 현재 브라우저의 로컬 저장소에 보관된다. 다른 기기와 공유하거나 장기 보관하려면 CSV로 내려받아 `data/performance.csv`에 통합한다. 여러 운영자가 동시에 사용해야 할 때는 로그인과 데이터베이스를 연결하는 다음 단계로 확장한다.
